# 图层混合

基于标准库的 RGBA 图层合成器。`Image`、`load_png`、`save_png`、`blend_pixel`、
`composite` 的接口保持不变，合成语义改为业界通用的直通（straight）alpha
合成公式，与 Photoshop 等常见图像软件一致。

## 合成公式

设源图层像素 alpha 为 `a_s`（已乘上该层 `opacity`），底图 alpha 为 `a_b`，
`C` 为 0..1 的通道值，`B(C_b, C_s)` 为混合模式函数：

```
a_out = a_s + a_b * (1 - a_s)
C_out = (a_s*(1-a_b)*C_s + a_s*a_b*B(C_b,C_s) + a_b*(1-a_s)*C_b) / a_out
```

- `normal`：`B = C_s`
- `multiply`：`B = C_b * C_s`
- `screen`：`B = C_b + C_s - C_b * C_s`

关键点：

- 颜色全程在 0..1 浮点空间计算，输出四舍五入回 8 位并夹紧到 0..255，
  避免截断造成的色阶断层。
- 完全透明（`a_s = 0`）时公式退化为 `C_out = C_b`、`a_out = a_b`，因此透明
  像素的 RGB 不会以任何方式影响结果，任何模式下都不会出现灰块或黑边。
- 底图自身的 alpha 参与计算，透明底图不会被当成黑色。
- `composite` 严格按 `layers` 数组顺序逐层叠乘，每层使用自己的 `opacity`。
- 图层尺寸与底图不一致时按左上角对齐，越界部分裁剪，缺失部分视为透明。
- PNG 读写支持 8 位灰度 / RGB / RGBA 与非隔行扫描的全部 5 种行过滤；
  写出固定过滤 0、固定压缩级别，因此同样输入连续运行逐字节相同。

## 示例结果

底图 200x140 带横向渐变，三个图层依次为左上角半透明色块（normal，opacity 0.5）、
棋盘格正片叠底（multiply，0.35）、右上角光晕滤色（screen，0.8）。
区域平均色（RGBA，8 位表示，统计的是该矩形内所有像素的平均值）：

| 区域 | 合成前 | 合成后 |
| --- | --- | --- |
| 左上（x 0–99, y 0–69） | 69.30, 87.20, 120.00, 255 | 81.77, 74.06, 88.47, 255 |
| 中部棋盘（x 20–179, y 50–129） | 99.30, 131.20, 120.00, 255 | 97.40, 108.71, 96.10, 255 |
| 右上光晕（x 120–179, y 10–69） | 129.30, 91.20, 120.00, 255 | 140.84, 110.53, 116.91, 255 |

左上区域被半透明暗色块压暗并偏红；中部棋盘经 0.35 的正片叠底整体压暗；
右上光晕经滤色提亮。输出尺寸 200x140，与底图一致，连续两次运行输出
SHA-256 相同（`c98173f3…c211a`）。
