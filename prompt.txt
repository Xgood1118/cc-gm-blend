在现有 blend 骨架上，把它做成一个能正确处理透明度与混合模式的合成器。保留 Image、load_png、save_png、
blend_pixel、composite 的现有名字与签名，只用 Python 标准库，不得引入第三方依赖，不得改动
data/base.png 与三个图层图，也不得改动 data/stack.json 的模式与不透明度配置。

## 需要完成

1. **透明度**
   - 半透明图层叠在底图上时不能出现黑边或灰块。
   - 底图自身带 alpha 时，合成结果要与常见图像软件一致。
   - 透明区域的 RGB 不能影响结果。

2. **混合模式**
   - normal、multiply、screen 三种模式在纯色与渐变上的结果都要符合标准公式。
   - 透明像素在任何模式下都不能改变底图。

3. **不透明度**
   - 每层自己的不透明度要生效，0.35 与 1.0 的结果必须不同。
   - 多层叠乘顺序要按 `stack.json` 的数组顺序，顺序写反结果要不同。

4. **颜色**
   - 混合在正确的数值空间进行，输出不出现色阶断层。
   - 结果所有通道都在 0 到 255。

5. **输出**
   - PNG 尺寸与底图一致，连续跑两次逐字节相同。

6. **测试**
   - 覆盖：透明区不改变底图、三种模式公式、不透明度生效、顺序敏感、两次输出一致。
   - `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m blend.cli data/stack.json --out blend.png`，把三块区域（左上、中部棋盘、
右上光晕）合成前后的平均色贴进 README。
